Questions fréquentes

Comment changer de lecture (riwaya) ?

Dans Réglages, choisissez la lecture voulue. Ḥafṣ est incluse ; les autres se téléchargent une seule fois, puis restent disponibles hors ligne.

Pourquoi faut-il internet pour écouter ?

Les récitations sont lues depuis mp3quran.net au moment de l'écoute. La lecture, la traduction, l'exégèse et les hadiths fonctionnent sans connexion.

Comment couper les rappels ?

Dans Réglages, puis Rappels. Vous pouvez aussi les couper dans les réglages de notifications de l'iPhone.

Mes notes et marque-pages sont-ils sauvegardés ?

Ils restent sur votre téléphone, sans compte. Si vous supprimez l'application, ils sont supprimés avec elle.

D'où viennent les textes ?

Dalîl n'écrit aucun texte religieux. Chaque texte vient d'une source publiée, citée dans l'application, page « Sources et méthode ».
